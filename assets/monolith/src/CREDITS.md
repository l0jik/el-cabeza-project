# The Monolith's recordings

The sources of the Monolith's recorded sound (the Theme Lab's second
direction: real stone, struck, falling and dragged; user: "I want the sound
palette to be non-synthesizer generated. I want real massive: thud / boom /
scraping sounds"), and what `tools/monolith_sounds.mjs` makes of each. All
nine came straight from freesound.org, each its uploader's HQ MP3 preview,
fetched through the page reader; each licence checked on the recording's
own page. Nothing is synthesized: the tool only cuts, fades, high-passes
the rumble under each and sets its level. The game credits them on the
About card (themes/lab/specs.js, the monolith's `soundCredits`).
